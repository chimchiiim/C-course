Лабораторная работа № 4. Обработка одномерного массива 📦

📖 Теория

Массив — это ряд ячеек в памяти компьютера. У каждой ячейки есть свой порядковый номер (индекс, который всегда начинается с 0), и в каждой хранится значение строго одного типа (например, только целые числа int).

🛠 Как это работает на практике

Для ввода данных мы используем scanf, а для вывода — printf. Чтобы заполнить массив, нам нужен цикл for. При чтении чисел не забывай ставить знак амперсанда & перед элементом массива, чтобы передать его адрес!


int arr[5]; // Создали массив на 5 элементов
// Считываем 5 чисел с клавиатуры
for(int i = 0; i < 5; i++) {
    scanf("%d", &arr[i]); 
}

🎯 Твоя практика

Задание: Напиши программу, которая считывает массив из 5 целых чисел, а затем выводит на экран (через printf) только положительные числа из этого массива.
